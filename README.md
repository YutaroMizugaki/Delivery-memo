# Delivery-memo

日本語の納品書（納品メモ）をブラウザ上で作成・印刷できるWebアプリです。

## 機能

- 発行元・納品先・明細の入力
- 金額・消費税の自動計算
- 金額表示のオン/オフ切り替え
- 発行元情報・下書きのローカル保存
- 印刷 / PDF出力（ブラウザの印刷機能）

## 使い方

1. `index.html` をブラウザで開く
2. 左サイドバーで発行元・納品先・書類情報を入力
3. 下部の明細行で品目を追加・編集
4. 「印刷 / PDF」ボタンで印刷またはPDF保存

### ローカルサーバーで起動（推奨）

```bash
# Python
python3 -m http.server 8080

# Node.js (npx)
npx serve .
```

ブラウザで http://localhost:8080 を開いてください。
